| `intercepting-call-sites` | Intercepting call sites | 300 | What an interceptor is: scope, target, provider, placement. Difference from overriding. Terminology note: the interceptor is the method that the rewritten call site calls, as in C# interceptors, and Metalama interceptors are not C# `[InterceptsLocation]` interceptors (section [0.4](00-conventions.md#04-terminology-aligned-with-roslyn-interceptors)). When to use it. How it works: rewrite of source call sites at build time, not visible at design time. Terminology: a registration has a scope (the calling side) and a target selection; a site has an origin, which the scope must contain, and a destination, which is the member or the awaitable type that the site uses; a synthesized interceptor has a placement (section [0.3](00-conventions.md#03-terms)). Child-article table. |
