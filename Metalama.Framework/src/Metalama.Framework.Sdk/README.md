## About

`Metalama.Framework.Sdk` allows you to extend Metalama using the Roslyn API.

## Key Features

It includes three use cases:

- **Inspecting method bodies** using Roslyn's syntax tree and symbols (Metalama's code model does not give you access to this level of detail.)
- **Build custom aspect weavers** to create aspects that perform arbitrary syntax tree transformation.
- **Build custom metrics**.

## Resources

## AI Coding Assistants

If you use an AI coding assistant such as Claude Code, install the [Metalama AI Skills](https://github.com/metalama/Metalama.AI.Skills) plugin. It gives the assistant access to the Metalama conceptual documentation, the API reference, and code samples.
