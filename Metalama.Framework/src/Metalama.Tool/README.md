## About

Metalama Command Line Tools is used for registering a Metalama license key, configuration, and troubleshooting.

## Commands

* `metalama license`: manage license registrations
* `metalama config`: edit or reset JSON configuration files
* `metalama cleanup`: delete temporary files
* `metalama kill`: shuts down or kills processes that may be locking Metalama packages
* `metalama telemetry`: manages the telemetry options and upload queue
* `metalama docs`: opens the Metalama documentation
* `metalama ui`: opens the configuration browser-based UI
* `metalama divorce`: copies code generated by Metalama back into your source code, in case you wanted to stop using Metalama
* `metalama introspect`: queries how Metalama applied aspects to a project, from the introspection file of its last build (see below)

## Introspection

The `metalama introspect` commands answer questions such as "which aspects apply to this method, and what do they change?"
without building the project. They read the introspection file (`.mlsym`) that the build writes next to the output
assembly when the `MetalamaWriteIntrospectionFile` MSBuild property is `True`:

```
dotnet build -p:MetalamaWriteIntrospectionFile=True
metalama introspect show declaration src/Customer.cs:18
metalama introspect list aspect-instances --where "aspectClass/shortName eq 'Log'"
metalama introspect schema
```

The property is off by default. Set it in `Directory.Build.props` to write the file in every build. The
`MetalamaIntrospectionFile` property changes the path of the file. The feature requires no license.

## AI Coding Assistants

If you use an AI coding assistant such as Claude Code, install the [Metalama AI Skills](https://github.com/metalama/Metalama.AI.Skills) plugin. It gives the assistant access to the Metalama conceptual documentation, the API reference, and code samples.
