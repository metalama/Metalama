The `Metalama.Backstage.Configuration` package is not meant to be directly referenced in user projects.

It contains the file-based configuration manager of Metalama.Backstage: the configuration files stored in the application data directory of the user. It is a dependency of the [Metalama.Backstage](https://www.nuget.org/packages/Metalama.Backstage) package, which composes these services for Metalama.
