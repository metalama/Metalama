The `Metalama.Backstage.Core` package is not meant to be directly referenced in user projects.

It contains the core infrastructure services of Metalama.Backstage: dependency injection, diagnostics, the file system, named locks, temporary files and the configuration contract. It is a dependency of the [Metalama.Backstage](https://www.nuget.org/packages/Metalama.Backstage) package, which composes these services for Metalama.
