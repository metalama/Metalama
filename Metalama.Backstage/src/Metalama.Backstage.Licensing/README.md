The `Metalama.Backstage.Licensing` package is not meant to be directly referenced in user projects.

It contains the licensing services of Metalama.Backstage: license keys, license registration, license consumption and the license audit. It is a dependency of the [Metalama.Backstage](https://www.nuget.org/packages/Metalama.Backstage) package, which composes these services for Metalama.
