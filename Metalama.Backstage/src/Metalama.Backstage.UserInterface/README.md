The `Metalama.Backstage.UserInterface` package is not meant to be directly referenced in user projects.

It contains the user interface services of Metalama.Backstage: notifications, news, the welcome page and the setup pages. It is a dependency of the [Metalama.Backstage](https://www.nuget.org/packages/Metalama.Backstage) package, which composes these services for Metalama.
