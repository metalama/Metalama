The `Metalama.Backstage.Core.Desktop.Windows` package is not meant to be directly referenced in user projects.

It contains the desktop notifier of Metalama.Backstage for Windows as a library: the toast notifications and the browser window. Each product hosts it in a small executable that registers its own Backstage services; the executable of Metalama is `Metalama.Backstage.Desktop.Windows`.
