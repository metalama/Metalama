The `Metalama.Backstage.Telemetry` package is not meant to be directly referenced in user projects.

It contains the telemetry services of Metalama.Backstage: usage sessions, exception reports and their upload. It is a dependency of the [Metalama.Backstage](https://www.nuget.org/packages/Metalama.Backstage) package, which composes these services for Metalama.
