This package contains the PostSharp API with `[Obsolete]` annotations documenting its Metalama equivalent.

The package must be removed after the migration is complete.

## Documentation

* [PostSharp API Migration](https://doc.metalama.net/preview/api/migration-api)
* Conceptual Documentation: [Migrating from PostSharp](https://doc.metalama.net/preview/conceptual/migration)

## AI Coding Assistants

If you use an AI coding assistant such as Claude Code, install the [Metalama AI Skills](https://github.com/metalama/Metalama.AI.Skills) plugin. It gives the assistant access to the Metalama conceptual documentation, the API reference, and code samples.
